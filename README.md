# AK–47 · 形态档案

## 模型档案

- 001：AK–47，经典木材与钢制外观。
- 002：M1913，按用户提供的侧面照片近似重建，包含圆背套筒、后部防滑槽、开口护圈、纵纹握把和圆形徽章。厚度与未展示的另一侧为艺术化补全。
- 点击顶部“枪械目录”或标题下“浏览全部枪械”打开统一目录，可按型号、别名、编号、年代和材质搜索，按手枪/步枪筛选，按编号、名称或年代排序。点击卡片进入模型；Escape 可关闭目录。
- `/#ak47` 和 `/#m1913` 可直接打开对应模型。各模型均支持旋转、视角切换、开火体验及导出当前模型为 GLB；“枪口特写”可近距离检查枪口。
- M1913 使用分层颜色、粗糙度与凹凸纹理表现钢材氧化、拉丝和细小磨痕；展厅加入环境反光。枪口前端为开孔网格，包含外圈和内壁的视觉结构。
- M1913 的连发沿用展厅视觉体验，不表示真实枪械的工作模式；不包含内部功能结构。

基于 Three.js 的 AK-47 外观展示原型。模型使用代码生成，包含木托、护木、机匣外壳、握把、弧形弹匣和外部瞄具等视觉元素；采用艺术化比例，仅用于外观展示。

## 运行

日常查看：双击项目根目录的 `start-preview.cmd`，会启动后台预览并在默认浏览器打开。关闭浏览器或结束聊天不会主动关闭预览；电脑重启后重新双击即可。需要已安装 Node.js。

预览地址：`http://127.0.0.1:5173/`。这是本机地址，需要本机预览服务运行才能访问。

开发和修改模型：

```powershell
npm install
npm run dev
```

打开终端输出的本地地址。请通过开发服务器浏览，不要直接双击 HTML。

## 操作

页面顶部可切换“模型展厅”和“矩阵靶场”。靶场也可直接访问 `http://127.0.0.1:5173/range.html`。

### 矩阵靶场

- 固定 5×5 矩阵，小球每隔约 0.35～0.65 秒依次随机闪出，同时出现上限可选 1～5 个，默认 3 个；已有小球不会阻止后续小球出现，达到上限时暂缓生成。
- 每个小球随机停留 1～2 秒，外圈显示剩余时间。命中即消失，未命中则超时自动消失并计入超时数量；同屏格位不重复。
- 整场练习总时长可选 0.5～3 分钟，步长 0.5 分钟，默认 1 分钟。
- 点击小球记为命中，点击矩阵空白记为未命中；后续小球按节奏独立出现，到时自动结束。命中率按命中数 / 射击次数计算，超时单独统计。
- 实时显示剩余时间、命中数、射击次数和命中率，结束后显示成绩和从小球出现到命中的平均用时。
- 支持暂停、继续、提前结束和重新练习；练习中设置锁定。窗口失焦或页面隐藏时自动暂停，回到页面后手动继续。

### 模型展厅

- 鼠标左键拖动：旋转；滚轮：缩放；右键拖动：平移。
- 触屏单指旋转、双指缩放或平移。
- 页面右侧支持透视、侧面、俯视和自动旋转。
- 点按“开火”单发，长按持续开火，松开即停止。按钮聚焦时也可长按空格或 Enter；页面隐藏、窗口失焦、触摸取消时自动停止。
- 射速可调 120–1200 发/分钟，默认 600；音效可选择经典、厚重、清脆，并调节音量（0–100%）和音调（0.70–1.30×）。音效与后坐、闪光、火星、轻烟按每发同步触发。“声音”按钮可静音。
- 音频在首次按下时启用，无需下载外部素材。
- 枪声为 Web Audio 合成效果，并非 AK-47 实录。震动为模型和画面动画；减少动态效果的系统偏好会降低震动幅度。
- 底部可切换三种木材饰面、重置视角。
- 点击页面底部“下载模型”可导出 GLB 外观模型；浏览器开发者控制台也可调用 `exportModel()`。

项目根目录已提供 `ak47-exterior.glb` 模型和 `preview.jpg` 效果预览。

### 第一人称持枪

- 展示页“选择视角”中点击“第一人称”，使用当前选中的 AK–47 或 M1913。
- 右手主握、左手辅助：步枪左手支撑护木；手枪左手包覆辅助。骨骼手部使用战术手套材质，并连接部分前臂。
- 进入第一人称即启用鼠标观察，无需按住任何按键即可转头；左键点按单发、长按连发，松开只停止射击，不停止观察。
- 按 Esc 退出视角控制并释放鼠标，可操作右上角退出或更换枪械；点击“继续观察”恢复鼠标控制，该操作不会开枪。
- 浏览器不支持或拒绝鼠标捕获时，鼠标在三维画面内移动仍可直接转头。触屏保留按住拖动观察及射击的操作。
- 射击包含手与枪共同后坐、食指动作、枪口闪光、火星、烟雾与合成枪声。使用展厅中设置的射速和声音参数；失焦、隐藏页面或打开目录会停止开火。
- 退出后恢复展厅摄像机、灯光与旋转操作；在第一人称中改变窗口大小后退出，会重新适配展厅构图。
- 右键切换瞄准、左手持枪设置和 WASD 行走已记录为后续需求，详见 `docs/first-person-plan.md`。
- 手部 GLB 随项目提供，来源及 MIT 许可见 `public/models/hands/`；前臂与手套材质由本项目生成。

## 扩充目录

`src/catalog.js` 是目录信息的统一入口，新增型号时填写唯一 `id`、名称、编号、年代、类别、别名和材质；目录卡片、搜索、筛选和计数自动生成。在 `src/main.js` 的 `archives` 中注册对应模型构建结果、展示位置和枪口特效位置，并在 `src/first-person-config.js` 添加该枪的显示比例、位置和左右手握姿配置。新增类别时同步扩充目录筛选选项。

`npm run build` 构建静态网站到 `dist`，可部署到静态托管服务。`npm test` 运行目录、枪械网格、开火节奏、第一人称骨骼姿态与靶场规则测试。

字体使用 Google Fonts，无法联网时自动回退到系统字体；枪械模型由本地代码生成，手部模型使用项目内的 GLB 文件，运行时无需下载远程模型。
