## 实现方案

### 第一人称持枪层

在现有 Three.js 场景中增加跟随摄像机的 `viewmodelRoot`，组合现有枪械网格和带骨骼双臂。第一人称使用独立的构图参数，进入和退出该模式时切换观察控制，并恢复展示页的摄像机状态。

用不同层级分别处理第一人称位置、待机晃动和射击后坐，避免现有射击逻辑覆盖持枪定位。手臂与枪械的动作需共同协调，保证射击时手掌仍贴合握持位置。

### 按枪型与单枪适配

- 手枪：右手握枪柄，左手包覆右手提供辅助支撑。
- 步枪：右手握握把，左手支撑护木。
- 共用一套手臂骨骼，为两类枪保存不同的手臂和手指姿态。
- 为每把枪配置显示比例、偏移、左右手握持点、瞄准参考点和枪口参考点。
- 必要时使用手臂 IK 将手掌对齐握持点；手指姿态单独校准，避免穿模。
- 左右手模式使用独立姿态与适配配置，后续校验文字、抛壳及枪械结构的显示。

### 射击与瞄准

首期复用现有射击逻辑与效果，调整后坐驱动方式，让手与枪同步运动；检查新增父级变换后的枪口特效世界坐标和方向。

后续实现右键切换瞄准状态，平滑过渡至照门、准星与视线对齐的位置。瞄准状态和射击状态分别管理，使腰射与瞄准射击都可用。

### 后续行走

预留摄像机观察、角色平移及持枪局部动作的独立层级，后续加入 WASD 行走。届时再确定移动范围、速度、碰撞、地面约束及行走晃动；这些细节本轮尚未确认。

## 实施顺序

1. 第一人称模式入口、鼠标观察与枪械显示。
2. 带骨骼手臂接入，分别校准手枪和步枪的右手主握双手姿态。
3. 腰射动作、手枪与步枪射击反馈，以及切枪时的姿态切换。
4. 右键切换瞄准及瞄准射击。
5. 左手持枪设置。
6. WASD 行走。后续阶段的具体先后可再调整。

## 首期验收目标

- 展示页可以进入和退出第一人称模式，并使用当前选中的枪械。
- 鼠标观察和左键射击可用，退出模式后展示页操作正常。
- 手枪与步枪具有明确不同的双手握姿，主要观察角度下没有明显穿模或悬空。
- 射击时手与枪协调运动，枪口效果的位置与方向正确。
- 切枪后应用对应的握姿和显示配置。
- 首期验收无需瞄准射击、左手模式或 WASD 行走完成。

## 首期实现与验证记录（2026-11-04）

- 已接入展示页模式入口、鼠标观察、腰射、双手同步后坐与食指动作、模式内切枪，以及退出后的展厅状态恢复。
- 已适配桌面与窄屏构图，并为不支持鼠标捕获的浏览器提供拖动观察方式。
- 手部采用 WebXR Input Profiles 的 MIT 授权骨骼 GLB；前臂为本项目生成的配套网格。当前没有引入完整上臂骨骼或手臂 IK，固定握姿由单枪配置控制，满足首期原地持枪。
- `viewmodelRoot` 跟随摄像机，独立 `recoilRoot` 同时驱动双手和枪械；左右手各保留真实骨骼与手指姿态，没有通过负缩放镜像手部。
- 第一人称构图隐藏贴肩枪托，避免肩部网格覆盖主握手；退出展示和导出 GLB 时仍保留完整枪托。
- 新增骨骼与观察逻辑测试，覆盖俯仰限制、枪械朝向、后坐恢复、实际 GLB 骨长保持、顶点有限值和食指动作可逆性。
- 后续待办仍包括：右键切换瞄准及瞄准射击、左手模式、WASD 行走及其移动范围/碰撞/地面约束；未合并到 `main`。

### 鼠标控制修正

- 第一人称进入后直接启用鼠标转头，与射击按键分离；松开左键只停止射击。
- Esc 暂停视角控制并释放鼠标；“继续观察”恢复控制且不触发射击。
- 浏览器不支持 Pointer Lock 时使用画面内自由鼠标移动，不再要求按住左键拖动。
- 失焦、页面隐藏、浏览器释放鼠标或打开目录时暂停控制并停止射击。

### 腰射构图调整

- 参考 CS / VALORANT 常见的右手腰射构图：枪身位于右下，枪口在准星右下方，中央视野保持开阔。采用相似构图原则，不复制游戏模型或宣称复刻其内部参数。
- 两把枪分别下移、右移、拉远并调整朝向，增加枪身侧面的可见度，避免原先过近、过高的后部遮挡。
- 前臂出口按枪械分别配置，随持枪位置自然落向画面下方。
- 朝向进一步校准为主要朝正前方：步枪水平内扣约 8°，手枪约 7°，保持右下腰射位置，避免过度向准星汇聚。
